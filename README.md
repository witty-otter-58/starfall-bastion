Starfall Bastion: a tower defence about holding the last starlight against twenty waves of void creatures. Five tower types, upgrades, six enemy kinds with a boss every fifth wave, an economy of kill bounties and wave bonuses, and a full game loop — title, play, pause, victory, defeat — with synthesized sound and no network at all.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080. No build step, no dependencies, no downloads: the whole game is the files in `game/`.
